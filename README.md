# Telegram Messenger

Cross‑platform desktop messenger using PyQt5 and Telethon.

## Features

- Text and media messages (photos, documents)
- Local chat history (SQLite)
- System notifications for new messages
- Dialog list with unread counters
- MTProto proxy support (bypass network restrictions)
- Works on Windows and Linux

## Setup

1. Obtain API ID and API Hash from [my.telegram.org](https://my.telegram.org)
2. Install Python 3.8+ and dependencies:
